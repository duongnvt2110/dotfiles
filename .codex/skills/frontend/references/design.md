# Frontend Design

Implement browser-facing UI with repository-consistent visual hierarchy and interaction behavior.

## Procedure

1. Inspect the existing design system/components before creating new primitives.
2. Match spacing, typography, color, states, accessibility, and interaction conventions.
3. Prefer composition of existing components over parallel design systems.
4. Verify important states, not only the happy-path screenshot.

For Figma-backed work, use the maintained Figma integration for design interpretation and `$figma-cache-fallback` only when cache/throttling recovery is required.
