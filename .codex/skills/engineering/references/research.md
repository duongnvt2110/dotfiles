# Research

Gather evidence before recommendations. Choose the lightest research mode that can answer the question.

## Modes

- Local repository research
- Documentation research
- Deep external research
- Zoom-out / comparative research

## Procedure

1. Start with the local repository when the request concerns existing code or behavior.
2. Use current documentation when external library/API behavior materially affects the answer.
3. Escalate to deep external research only when local evidence and primary documentation are insufficient.
4. Use zoom-out or comparative research only when the decision genuinely depends on alternatives.
5. Record findings with source/evidence and separate facts from inference.

## Guardrails

- Evidence first; recommendations second.
- Research may broaden understanding but must not broaden implementation scope by itself.
