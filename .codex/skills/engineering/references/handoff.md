# Handoff

Transfer enough factual state for another engineer or agent to continue without replaying the conversation.

## Procedure

1. State the current goal and approved scope.
2. List completed work and changed files.
3. Record verification actually performed and its result.
4. List known issues/limitations separately from speculative ideas.
5. State the next concrete action and any blocking decision.

## Guardrails

- Use the fields: Current goal, Completed work, Changed files, Verification, Known issues, Next action.
- Keep the handoff agent-neutral.
