# Figma Detail Extraction

Turn inspected Figma data into implementation-relevant structured details.

## Procedure

1. Extract component hierarchy and reusable patterns.
2. Record dimensions/constraints, tokens/styles, assets, variants, and states.
3. Normalize repeated design values without inventing new tokens.
4. Flag missing/ambiguous design information explicitly.
